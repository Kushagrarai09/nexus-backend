# Nexus Backend Engineering Roadmap

## Phase 1 — Internet and HTTP
Client/server, DNS, IP, ports, HTTP, HTTPS, headers, status codes, JSON, Node HTTP server.

## Phase 2 — TypeScript and Git
Types, interfaces, modules, async/await, event loop, errors, Git workflows.

## Phase 3 — API engineering
Express, REST, middleware, validation, pagination, filtering, OpenAPI, API versioning, GraphQL/SOAP/gRPC comparisons.

## Phase 4 — Data engineering
PostgreSQL, SQL, relations, normalization, indexes, ACID, isolation, locks, migrations, ORM, N+1, profiling.

## Phase 5 — Security
Password hashing, sessions, JWT, refresh rotation, OAuth2/OIDC/SAML, RBAC, OWASP, TLS, CORS, CSP, secrets.

## Phase 6 — Performance
Redis, cache-aside, invalidation, TTL, CDN concepts, rate limiting, pooling, profiling.

## Phase 7 — Quality
Unit, integration, functional, contract and load testing; TDD; CI/CD.

## Phase 8 — Architecture
SOLID, GoF, layered/clean architecture, DDD, modular monolith, CQRS, event sourcing, twelve-factor applications.

## Phase 9 — Messaging
RabbitMQ, Kafka, queues, topics, retries, DLQ, idempotent consumers, outbox.

## Phase 10 — Distributed systems
Microservices, gateway, gRPC, GraphQL, WebSockets, SSE, CAP, consistency, sagas, circuit breakers, backpressure, graceful degradation.

## Phase 11 — Infrastructure
Linux, Docker, Compose, Nginx, Kubernetes, deployment, secrets and infrastructure automation.

## Phase 12 — Scale and observability
Replication, sharding, NoSQL comparisons, Elasticsearch, metrics, logs, traces, telemetry, SLOs, load and failure testing.

## Completion rule
A topic is complete only after explanation, implementation or controlled experiment, tests, failure analysis and documentation.
